# MDM2
You can update what you have done and different python files here, and text files explaining what they do
To update them to the main repository look on the left hand bar to the branch icon
Click on it, then click the + next to each file or on Stage All Changes.
Type a commit message at the top and click the checkmark to commit.
​(Or in the thing that pops up type your message there)

We can now see all the changes made in the graph in the bottom! Yay!
